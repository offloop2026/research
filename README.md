# 사물 아카이브 (OBJECT REPOSITORY)

사물을 수집하고 사진, 시간, 메모, 성좌(관계)를 통해 시각적으로 기록하고 축적하는 독립적인 디지털 사물 아카이브입니다.

블로그, 포트폴리오, 콘텐츠 플랫폼, 수업 기록의 요소를 모두 배제하고, 아카이브 자료와 구조 자체가 사이트의 성격을 드러내도록 설계되었습니다.

---

## 1. 사이트 구조 (정확히 4개 네비게이션)

상단 네비게이션은 다음 4개의 메뉴만 유지합니다:

```text
[ 아카이브 ]    [ 성좌 ]    [ 시간 ]    [ 메모 ]                    [+ 등록]
```

- **아카이브 (`index.html`)**: 불필요한 소개 문구 없이 사물의 축적된 사진 목록([사진] → 사물 명칭 → 기록 일시)을 즉시 표시하며, 사물 클릭 시 대형 대표 사진, 썸네일 스트립, 일시, 성좌 연결, 메모 순으로 읽히는 상세 도록(Dossier)을 제공합니다.
- **성좌 (`constellation.html`)**: 각 사물의 `constellation` 데이터에 명시적으로 지정된 사물 간의 실제 관계만을 선으로 시각화한 인터랙티브 네트워크 맵입니다. 노드 호버 시 제목과 대표 사진 썸네일이 표시되며 클릭 시 해당 사물로 이동합니다.
- **시간 (`time.html`)**: 연도(Year) → 월(Month) → 일(Date) 계층 구조로 사물이 축적된 시점을 조망하는 시간축 탐색 인터페이스입니다. 가장 최근 기록이 상단에 배치됩니다.
- **메모 (`memo.html`)**: 별도의 작성/상세 페이지 없이 화면 자체가 하나의 거대한 기록 보드(Memo Board)로 기능하며, 스티커 메모(Note Slip) 형태로 화면에서 즉시 작성·수정·삭제할 수 있는 직접 기록 인터페이스입니다. 모든 메모는 특정 사물과 반드시 양방향(`Object ↔ Memo`)으로 연결됩니다.
- **+ 등록**: 상단 네비게이션과 동일한 메뉴로 취급되지 않도록 우측 상단에 작은 독립 유틸리티 버튼으로 배치되어 새 사물 등록 모달을 호출합니다.

## 2. 사물 및 메모 데이터 구조

### 2.1 Object 스키마
불필요한 설명/서사/수업 관련 필드를 일체 배제하고 명확한 최소 구조를 갖습니다:

```json
{
  "id": "obj-001",
  "title": "타이머 메커니즘",
  "images": [
    "assets/images/obj-001-1.svg",
    "assets/images/obj-001-2.svg",
    "assets/images/obj-001-3.svg"
  ],
  "representativeImage": "assets/images/obj-001-1.svg",
  "timestamp": "2026.09.17 10:30",
  "constellation": ["obj-002", "obj-003"]
}
```

### 2.2 Memo 스키마
메모는 독립적인 텍스트 단위이면서 반드시 대상 사물과 양방향으로 연결됩니다:

```json
{
  "id": "memo-001",
  "objectId": "obj-001",
  "title": "황동 톱니 마모선",
  "content": "회전축 세 번째 톱니 표면에 미세한 마모선이 남아있다. 태엽이 풀리며 발생한 마찰 흔적.",
  "timestamp": "2026.09.17 11:20"
}
```

## 3. 저장 및 정적 배포 구조 (LocalStorage 한계 해결)

- **공개 정적 데이터 (`data/archive.json`)**:
  - 사이트 배포 시 누구나 동일한 아카이브를 볼 수 있도록 기준 데이터셋이 정적 JSON으로 제공됩니다.
  - 새 방문자나 다른 기기/브라우저에서도 완전한 사물 도록 및 성좌 데이터가 즉시 로드됩니다.
- **로컬 사용자 추가 데이터 (LocalStorage 오버레이)**:
  - 브라우저에서 `+ 등록` 버튼이나 `+ 메모 작성`을 통해 등록한 사물 및 메모는 로컬 스토리지에 보관되며, 기본 정적 데이터셋과 결합하여 실시간으로 반영됩니다.

## 4. 디렉터리 구성

```text
archive-of-matter/
├── index.html            # 아카이브 (사물 목록 및 개별 사물 상세 뷰)
├── constellation.html    # 성좌 (관계망 인터랙티브 캔버스)
├── time.html             # 시간 (연/월/일 시간축 계층 뷰)
├── memo.html             # 메모 (사물 연결 기록 누적 뷰)
├── data/
│   └── archive.json      # 기본 아카이브 정적 데이터셋
├── assets/
│   └── images/           # 아카이브 사물 도판 및 사진 에셋
├── css/
│   ├── style.css         # 통합 마스터 스타일시트
│   ├── reset.css         # 기본 초기화
│   ├── typography.css    # 타이포그래피 토큰
│   ├── layout.css        # 4대 네비게이션 및 기본 레이아웃
│   ├── views.css         # 아카이브 목록, 상세, 시간, 메모, 라이트박스 뷰
│   └── constellation.css # 성좌 캔버스 스타일
└── js/
    ├── app.js            # 데이터 관리, 헤더 네비게이션, 등록 모달, 라이트박스
    ├── archive.js        # 사물 목록 및 개별 사물 도록 렌더링
    ├── constellation.js  # 성좌 관계 시각화 엔진
    ├── time.js           # 시간 계층별 그룹핑 및 렌더링
    └── memo.js           # 메모 축적 피드 및 사물 연결 렌더링
```
